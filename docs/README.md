# IMPRINT project page

Static, dependency-free project page for GitHub Pages.

## Add it to the repository

1. Copy `index.html`, `styles.css`, `script.js`, and `assets/` into the repository root, or into a `/docs` folder.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch, and select either `/ (root)` or `/docs` depending on where the files were copied.

## Replace the placeholder links

In `index.html`, search for:

- `Add video URL`
- `Add media URL`

Replace each `href="#"` with the final URL and remove `aria-disabled="true"`. You can also remove `<small>soon</small>`.
