## Setting up the Conda Env

```bash
# Create env
conda create -n imprint_onemap python=3.9 cmake=3.14.0 -y
conda activate imprint_onemap

#CUDA nvcc
conda install -c nvidia cuda-toolkit=12.6 cuda-nvcc=12.6 -y

# Dependencies
python3 -m pip install gdown torch torchvision torchaudio meson
python3 -m pip install -r requirements.txt

python3 -m pip install --upgrade timm>=1.0.7

# Build planning utils
python3 -m pip install ./planning_cpp/

# Habitat-Sim
conda remove cuda-toolkit -y
conda install habitat-sim=0.2.5 withbullet -c conda-forge -c aihabitat
```

## Setting up the Directory

Run these commands from the IMPRINT repository:

```bash
# Enter the OneMap baseline directory
cd IMPRINT/active_baselines/OneMap

# Clone the Habitat-Lab version used by this baseline, or link an existing checkout.
mkdir -p habitat-labs/v0.2.5
cd habitat-labs/v0.2.5
git clone --branch v0.2.5 https://github.com/facebookresearch/habitat-lab.git
cd habitat-lab
pip install -e habitat-lab
pip install -e habitat-baselines
cd ../../..
ln -s habitat-labs/v0.2.5/habitat-lab habitat-lab
```

Download the HSSD-Hab assets using Habitat-Sim's dataset utility, then make sure
the HSSD-rare episodes generated by IMPRINT are available at:

```text
habitat-lab/data/datasets/objectnav/hssd/val_rare/content/
```

The default configuration expects HSSD-Hab scenes at:

```text
habitat-lab/data/scene_datasets/hssd-hab/scenes/
```

For OVON evaluation, change the dataset paths and `is_hssd` setting in
`config/mon/eval_conf.yaml` to the OVON scene and episode locations.

## Evaluating IMPRINT

The active evaluator is `eval_habitat.py`, which loads
`eval/habitat_evaluator.py`. The default configuration targets HSSD-rare.

Run the standard OneMap baseline with text queries:

```bash
python3 eval_habitat.py \
      --config config/mon/eval_conf.yaml
```

Run IMPRINT with web-image query enrichment and the open-vocabulary detector:

```bash
python3 eval_habitat.py \
      --config config/mon/eval_conf.yaml \
      --PlanningConf.using_ov \
      --PlanningConf.multi_prompt \
      --PlanningConf.scrape_num 15
```

`multi_prompt` enables text-plus-image query features. Set it to `False` for
text-only or image-only ablations. `using_ov` enables the open-vocabulary
detector, and `multi_detect` additionally conditions detection on the retrieved
images:

```bash
python3 eval_habitat.py \
      --config config/mon/eval_conf.yaml \
      --PlanningConf.using_ov \
      --PlanningConf.multi_prompt \
      --PlanningConf.multi_detect \
      --PlanningConf.scrape_num 15
```

The image retrieval code caches downloaded reference images under the configured
scrape directory. Results are written to `results_dir` from the evaluation
configuration, including episode states, trajectories, similarity maps, and
optional Rerun logs.

To evaluate OVON, update `config/mon/eval_conf.yaml` with the OVON episode and
scene paths, set `is_hssd: False`, and run the same commands.
